# LLM Course, Explained

This site explains each section of the [LLM Course](https://github.com/mlabonne/llm-course) by Maxime Labonne.
The course lists what to learn. This site shows how each thing works, with one small example that you can calculate by hand.

## How each page works

1. **Core idea.** Two or three sentences, with no special terms.
2. **Sub-parts.** Each one has a **Setup**, numbered **Steps** and a **Key point**. Each step shows the calculation, then **why** you do it.
3. **From toy to real.** The same thing at the size of a real model.
4. **Comparison table**, then **checks and common misconceptions**.

Start with [the toy example](toy-example.md). All pages use its numbers.
